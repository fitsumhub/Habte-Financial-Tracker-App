# Habte v1.0.0 — Initial Release

**Habte (ሀብቴ)** is a privacy-first personal finance tracker built for the Ethiopian market.

## Highlights

- **Automated SMS sync** for Telebirr and 16 Ethiopian banks (CBE, BOA, Awash, Dashen, and more)
- **Real-time transaction capture** from incoming bank SMS notifications
- **Smart categorization** — Food, Bills, Transport, Income, and more
- **Biometric lock** — Fingerprint / Face ID on startup
- **Privacy mode** — Blocks screenshots with `FLAG_SECURE`
- **Balance masking** — Hide sensitive amounts with one tap
- **Analytics dashboard** — Spending trends and category breakdown
- **Financial tools** — Currency converter, loan calc, tax calc, CSV export
- **Payment Reminders** — Alarm-app-style recurring reminders for rent, loans, subscriptions and any other bill, with due-date notifications
- **Material 3 UI** — Dark/light themes with English & Amharic support

## Requirements

- Android 8.0+ (API 26)
- SMS permissions for automatic transaction sync

## Install

1. Download `Habte-v1.0.0.apk` below
2. Enable "Install from unknown sources" if prompted
3. Open Habte and grant SMS permissions
4. Transactions will sync automatically from your SMS inbox
